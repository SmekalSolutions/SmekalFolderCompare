# Smekal Folder Compare

**Free Windows folder comparison tool for comparing folders and identifying differences.**

Smekal Folder Compare is a Windows utility developed by **Smekal Solutions** to compare folders and identify differences between their contents.

## Features

- Compare folders and identify differences
- Identify added, removed, and modified files
- Compare folder structures
- Simple Windows interface
- Free for personal and commercial use
